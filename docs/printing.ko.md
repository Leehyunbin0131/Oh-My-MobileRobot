# 출력·인쇄 방법

[한국어 README](../README.md) · [English](printing.en.md) · [파일 목록](parts.ko.md)

`hardware/` 아래 각 부품의 `print/` 폴더에 있는 STL의 출력 방향과 슬라이서 설정, PDF 도면의 인쇄 방법을 설명합니다. 출력용 STL의 단위는 mm, 배율은 100%입니다. m 단위로 된 ROS 시각화용 메시는 [ROS 모델 파일](parts.ko.md#ros-models)에 따로 있습니다. 파일 형식과 다운로드는 [설계 파일 목록](parts.ko.md#file-formats)에 있습니다.

<a id="orientation"></a>

## 출력 방향

| 부품 | STL의 출력 방향·최대 높이 |
| --- | --- |
| 상판 | 평평한 겉면이 베드, 밑면 리브가 위 / 최대 높이 7 |
| 일반·180 mm·카메라 측면 판 | 평평한 겉면이 베드, 안쪽 리브가 위 / 최대 높이 3 |
| D435i V2 브라켓 | 평평한 카메라 접촉면이 베드 / 최대 높이 6.5 |
| 전장판 | 평평한 밑면이 베드, 보스가 위 / 최대 높이 6 |

원점이 XY 중앙에 있거나 옆으로 이동된 STL도 있으니 슬라이서에서 베드 중앙으로 옮기면 됩니다. Z 최솟값은 출력면에 맞춰져 있습니다. XY 크기가 가장 큰 부품은 220 × 200인 상판이며 250 × 250 베드를 기준으로 했습니다.

<a id="fit-check"></a>

## 체결 시험편 사용

[M3 체결 시험편](parts.ko.md#fit-coupon)은 전장판에 서포터를 체결할 때의 체결감을 비교하는 부품입니다. 본품과 같은 재료, 출력 방향, 설정으로 시험편을 출력해 비교합니다. 체결부 치수는 [전장판 설계 규격](design.ko.md#electronics-trays)에 있습니다.

<a id="slicer-settings"></a>

## 슬라이서 설정

필라멘트, 노즐, 적층 두께, 외벽 수와 수축 보정값은 사용하는 프린터와 재료에 맞게 설정합니다. 얇은 1 mm 표면이 슬라이서에서 누락되지 않는지 미리보기로 확인할 수 있습니다.

<a id="drawing-printing"></a>

## 도면 인쇄

PDF는 1:1 도면이므로 **실제 크기 / 100%** 설정으로 인쇄합니다. 용지에 맞춤을 적용하면 치수가 달라집니다. 상판과 카메라 도면의 50 mm 기준선을 측정해 인쇄 배율을 확인할 수 있습니다.

| 도면 | 페이지 구성·용지 |
| --- | --- |
| 상판 | 전체 배치 1쪽 A1 + 개별 판 4쪽 A3 |
| D435i 브라켓 | 부품·장착 공간 2쪽 A4 |
| 180 mm 측면 판 | 1쪽 A4 |

상판 전체 도면과 개별 도면을 원래 배율로 인쇄하려면 각각 A1, A3 용지가 필요합니다. 도면 파일은 [출력 부품 파일 목록](parts.ko.md#printed-parts)에 있습니다.
